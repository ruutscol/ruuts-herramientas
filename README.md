# Herramientas RUUTS

Utilidades pequeñas para el equipo de la tienda, publicadas con GitHub Pages.

- `programador-banners/`: genera las fechas en hora de Colombia (AAAA-MM-DD HH:MM) para los campos "Mostrar desde" y "Ocultar desde" de los slides de la sección Home · Banner.
- `variantes-producto/`: a partir del export de productos de Shopify y un xlsx con las combinaciones, genera el CSV de un solo producto con todas sus variantes, listo para importar sobrescribiendo por handle. Con el export de Simple Bundles & Kits, también genera el CSV 2 que asocia cada variante con sus productos y cantidades en la app.
- `generador-utms/`: arma links con UTMs en cuatro pasos (link, canal, campaña y pieza), con plantillas por canal, nombres normalizados (minúscula, sin tildes, con guiones) e historial en el navegador que se copia a Google Sheets.
