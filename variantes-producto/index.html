Variantes al producto

Sube el export de productos de Shopify y el xlsx con las combinaciones. Elige el producto, mira cómo quedarían las variantes y descarga un CSV listo para importar con solo ese producto. Nada se envía a Shopify desde aquí.

Paso 2

Combinaciones

Las columnas que digan "Tarro" o "Sabor" se juntan en una sola opción (Shopify permite máximo 3 opciones). Las demás columnas que cambian son otra opción; las que siempre tienen el mismo valor se ignoran.

Paso 3

Ajustes

Todas las variantes llevan este precio. El SKU se arma con el inicio, las iniciales de cada sabor con su cantidad y las 3 primeras letras de las otras opciones (ej. COMB3-GOGO-LM2-FP1-BEI). Déjalo vacío si no quieres SKU.

Así va a quedar

Faltan archivos

Sube los dos archivos para ver las variantes.

    1. En Shopify ve a Productos › Importar y sube el CSV.
    2. Marca Sobrescribir productos con el mismo handle.
    3. Las variantes que tenía el producto se reemplazan por estas. Descripción, imágenes, etiquetas y estado quedan como están en el export.
    Usa un export reciente: el CSV toma del export todo lo que no son variantes, así que si cambiaste el producto en Shopify después de exportar, vuelve a exportar. El inventario no se toca: las variantes nuevas quedan en 0.
